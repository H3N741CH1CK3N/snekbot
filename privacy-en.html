2. Scope of This Policy

This Privacy Policy explains how personal data is processed when the SnekBot Discord bot is used. Discord is separately responsible for processing within the Discord platform. Discord's own privacy terms also apply.

3. Data We Process

SnekBot processes only the data required to provide its features, protect the service and operate it correctly:

  • Discord user IDs, Discord server IDs and, where applicable, Discord usernames;
  • server membership and server-specific bot settings;
  • virtual balances, ledger entries, transfers and rewards;
  • Spot orders, Futures positions, S-Bot activity and portfolio information;
  • Casino and game profiles, virtual stakes, progress and results;
  • profile items, preferences, Premium status and personal display settings;
  • command, error and worker information in technical logs, which may contain Discord user and server IDs.

SnekBot does not receive users' Discord passwords or payment information. Global simulated market prices, price history, events, sentiment and market regimes are not personal user data.

4. Purposes and Legal Bases

  • Providing bot features: executing requested commands and maintaining the virtual economy, Article 6(1)(b) GDPR.
  • Security and abuse prevention: preventing duplicate transactions, exploits, spam and manipulation, and diagnosing technical errors, Article 6(1)(f) GDPR.
  • Legal obligations: processing where required to comply with applicable law, Article 6(1)(c) GDPR.

The legitimate interest is the secure, stable and fair operation of the bot and its virtual economy.

5. Server Separation and Global Data

Balances, orders, positions, games, profiles and most settings are stored separately for each Discord server. Global market prices apply to all servers. Certain user preferences and entitlements, such as Premium status, may be stored globally for each Discord user.

6. Storage and Retention

Personal data is retained for as long as a user uses SnekBot and the data is required to provide requested features, maintain verifiable virtual balances, prevent abuse or comply with legal obligations. Persistent bot data is stored in a PostgreSQL database controlled by the operator.

Technical logs containing Discord user or server IDs are retained only for as long as required for security and troubleshooting and are then rotated or deleted. Transaction and game histories remain available while required for balance verification, lifetime statistics or privacy exports. They are deleted when the associated user data is validly deleted and no open transaction prevents deletion.

7. Access and Deletion

Using the private Discord command /privacy, users can request a readable summary and, optionally, a technical JSON export of their stored data. The same command allows users to delete data for the current server or all of their SnekBot user data.

Deletion is temporarily blocked while open Futures positions, Spot orders or locked Deathroll rounds exist. These must first be closed or settled.

After deletion, a non-reversible cryptographic deletion marker may remain. It does not contain the readable Discord user ID and is used solely to prevent a one-time starting balance from being claimed again after deletion.

8. Recipients and Third-Party Services

Discord processes data relating to Discord accounts, servers, commands and interactions. This information site is hosted using GitHub Pages; GitHub processes technically necessary connection data when the site is accessed. The providers' own privacy notices also apply:

  • Discord Privacy Policy
  • GitHub Privacy Statement

Discord or GitHub may transfer data to countries outside the European Economic Area. Their privacy notices contain further information about safeguards and legal bases. SnekBot does not sell personal data.

9. Your Rights

Subject to the applicable legal requirements, data subjects have rights including access, rectification, erasure, restriction of processing, data portability and objection. They also have the right to lodge a complaint with a competent data protection supervisory authority.

10. Automated Decision-Making

No automated decision-making produces legal or similarly significant effects. Automated game evaluations, virtual market calculations and abuse limits relate solely to use of the virtual bot system.

11. Changes to This Policy

This policy will be updated when features, processing activities or legal requirements change. The current version will always be available at this URL.
